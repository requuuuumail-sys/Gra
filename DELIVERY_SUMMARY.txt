================================================================================
                      QUICK START (5 MINUTES)
================================================================================

1. ORGANIZE FILES:
   - Create app/src/main/java/com/zebuild/game/
   - Copy 4 .java files there
   - Create app/src/main/res/layout/
   - Copy 3 .xml layout files there
   - Create app/src/main/res/values/
   - Copy colors.xml, strings.xml, styles.xml
   - Create app/src/main/res/drawable/
   - Copy all 21 drawable .xml files

2. OPEN IN ANDROID STUDIO:
   - File → Open
   - Select zebuild folder
   - Wait for Gradle sync

3. BUILD APK:
   - Build → Build APK(s)
   - Wait for "Build finished successfully"

4. INSTALL:
   - Find APK at app/build/outputs/apk/debug/app-debug.apk
   - Install on Android device
   - Play!
